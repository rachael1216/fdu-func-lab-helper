# 实验信息采集

每轮只问一组，学生答不上来就记为“未记录”，**不要替他补**。

1. 基本信息：实验编号/名称、日期、小组、动物种类与体重、麻醉方式与剂量。
2. 给药方案：药名、浓度、剂量（mg/kg 或 ml）、途径、给药时刻。（剂量换算交给 `labcalc.py dose`）
3. 时间轴：每个处理点与对应指标读数（心率、血压、呼吸、心电、尿量……）。要求学生按“时间点 | 指标 | 数值 | 单位”逐行给，或粘贴记录单文字。
4. 定性观察：波形/行为/体征的变化（学生自己的话）。
5. **与讲义不同的地方**：操作失误、药物更换、动物状态不佳、仪器问题。这一项最重要，直接决定讨论怎么写。
6. 图：DeepSeek 看不到图片，请学生用文字描述峰值/拐点，或给出读数。

产出：一张 Markdown 表（原始数据）+ 一段“实际操作与偏差”清单，向学生确认后再进入下一步。
