# 分析与讨论协议

**输入**：学生的数据/观察 + 知识卡的「机制链」「预期现象」「常见偏差」。

按下面顺序写，每步标注依据来源（学生数据 / 知识卡 / 教材页）：

1. **观察（事实）**：只陈述学生数据，带数字与单位，指出变化方向与幅度。
2. **预期对照**：与知识卡“预期现象”比较——一致 / 部分一致 / 不一致。
3. **机制解释**：沿机制链逐环解释一致的部分，每一环对应一个可观测指标。
4. **偏差解释（假设）**：不一致处，从“常见偏差”卡片列出 2–3 个候选原因，写成“可能是……，可通过……验证”，**不要下定论**；并核对学生在采集阶段记录的实际操作偏差，优先采用有记录支撑的原因。
5. **局限**：样本量（n）、测量误差、动物个体差异、麻醉影响。
6. **临床联系**：1–2 句，引用卡里的临床联系，不扩写成教科书。
7. **结论**：每个实验目的一句。

禁止：编造文献/数据；把假设写成事实；用“显然、众所周知”跳过机制；n=1 时写统计显著。
学生的语言风格优先，不要写成公文腔；篇幅宁短勿水。
