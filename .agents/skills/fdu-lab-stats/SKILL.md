# 统计分析助手

一律用 `python tools/labstats.py`，不心算；把命令和输出贴给学生核对。

## 先选方法
`python tools/labstats.py advise --groups 2 --n 5`

| 情形 | 方法 |
|---|---|
| 两组独立，近似正态 | `ttest --a … --b …`（默认 Welch） |
| 同一动物前后 | `ttest --a … --b … --paired` |
| 三组及以上 | `anova --g 对照=… --g 低=… --g 高=…`（含 Tukey） |
| 明显偏态/等级 | `mannwhitney --a … --b …` |
| 两个连续量的关系 | `corr`、`linreg` |
| 质反应（剂量-死亡率，如 LD50） | `python tools/labdose.py --dose … --n … --deaths … --figs 目录`：改良寇氏法 + Probit/Logit 拟合、似然剖面 CI、AIC、拟合优度、bootstrap、留一法、作图 |

## 约定
- α = 0.05 双侧。P 值写“P = 0.020”，< 0.001 写“P < 0.001”；不写“P = 0.000”。
- **n = 1：只描述，不检验。n < 3 不做检验。** n ≤ 5 时正态性检验几乎无检验力，工具会提示。
- 同一动物的多个时间点不是独立样本，不要当成多组做 t 检验；用配对或写变化量。
- 多重比较要校正（ANOVA 后用 Tukey，不要两两 t）。
- 统计只回答“差异是否可能由随机波动造成”，**不回答机制**；机制走 `fdu-lab-analysis`。
- 结果写入报告：均值 ± SD（n = x），检验名、统计量、自由度、P 值，例如“t(4) = −3.82，P = 0.020”。
- 全班合并数据时先问清每条数据来自哪只动物，别把重复测量当独立样本。
