# 报告自查

逐项检查并**列出问题清单 + 建议**，不要直接大改学生文字：

- [ ] 摘要/结果/讨论中的同一数字是否一致；单位是否齐全
- [ ] 每个表图有编号与标题，并在正文被引用
- [ ] 讨论中每个结论都能在结果里找到数据支撑
- [ ] 偏差是否写成假设，而非事实
- [ ] n=1 / 小样本是否有统计过度表述
- [ ] 剂量、浓度、体积是否用 `labcalc.py` 复算过
- [ ] 参考文献是否真实存在（不确定的标“待核实”，不要保留）
- [ ] 封面信息、页眉、日期是否正确；示例文字/提示块是否已删除
- [ ] 按课程要求写明 AI 使用情况（`ai_statement`）
- [ ] 全文无复制自他人/往届报告的段落

输出格式：按严重度（必须改 / 建议改 / 可选）分组。
