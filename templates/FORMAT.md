# 报告格式规范

本规范是 Word 与 LaTeX 两套通用模板的共同依据。若任课教师当年另有要求，**以教师要求为准**，再改 `tools/make_reference_docx.py`（Word）或 `templates/latex/fdureport.cls`（LaTeX）中的对应数值即可。

## 1. 结构

| 部分 | 内容与要求 | 篇幅参考 |
| --- | --- | --- |
| 封面 | 学校与课程、题目、线稿插图、班级、姓名、学号、日期；不放校徽 | 1 页 |
| 目录 | 一、二级标题，罗马页码（Ⅰ、Ⅱ…） | 1 页 |
| 摘要（不编号） | 依次写目的、对象与方法、主要结果（含关键数字）、结论；末尾列 3–5 个关键词 | 200–300 字 |
| 1 引言 | 实验涉及的生理、病理或药理问题；教材或文献依据；最后一句写实验目的 | 1–2 段 |
| 2 材料与方法 | 2.1 对象与药品（种类、体重、剂量、浓度、途径）；2.2 实验步骤（按时间顺序）；2.3 观察指标与数据处理（定义、公式、统计方法）。与实际操作不一致处如实写明 | 1–1.5 页 |
| 3 结果 | 先文字概括，再放表图；只陈述事实与数据，不作解释 | 1–2 页 |
| 4 讨论 | 主要发现 → 机制解释 → 与预期不符处的可能原因（写成假设）→ 局限 → 临床联系 | 1–2 页 |
| 5 结论 | 2–3 句，与目的一一对应，不引入新数据 | 3–5 行 |
| 参考文献（不编号） | GB/T 7714—2015 顺序编码制，正文以 [1] 引用 | 按需 |
| 附录（可选） | 原始数据、计算过程、代码 | 按需 |

## 2. 字体与版面

| 项目 | 规定 |
| --- | --- |
| 纸张与页边距 | A4；上下 2.54 cm，左右 3.0 cm |
| 正文 | 宋体（英文数字 Times New Roman），小四（12 pt），1.5 倍行距，首行缩进 2 字符 |
| 题目（封面） | 黑体，26 pt 加粗 |
| 一级标题 | 黑体三号（16 pt）加粗，编号 1、2、3 |
| 二级标题 | 黑体四号（14 pt）加粗，编号 1.1 |
| 三级标题 | 黑体小四（12 pt）加粗，编号 1.1.1 |
| 图表题注与表内文字 | 宋体五号（10.5 pt）；表题在表上，图题在图下，居中 |
| 参考文献 | 宋体五号，悬挂缩进 |
| 页眉 | 左：课程名（含线稿小图标）；右：学号；下划细线 |
| 页脚 | 居中页码；目录用罗马数字，正文从 1 起用阿拉伯数字 |

## 3. 数字、单位与符号

- 数值与单位之间留半角空格：`2.58 kg`、`0.5 mg/kg`；百分号紧跟数字：`27.3%`。
- 变量与统计符号用斜体（*n*、*P*、*t*）；单位与化学式用正体。
- 离子与下标：Ca²⁺、K⁺、H₂O（Word 直接输入，LaTeX 由构建脚本转换）。
- 均值与离散程度写作 `x̄ ± s`（或 mean ± SD），在表注或方法中说明；*P* 值写出具体数值，小于 0.001 写 *P* < 0.001。
- 小数位数与测量精度一致，同一指标保持一致。
- 剂量写作 mg/kg，体积写作 mL，时间写作 min、s，压力写作 mmHg 或 kPa（全文统一）。

## 4. 表

- 采用三线表：顶线、底线 1.5 磅，表头下线 0.75 磅，无竖线。
- 表题格式：`表 1　题目`，写在表上方；自明（读者不看正文也能知道内容）。
- 单位放在列标题里，如 `心率（次/min）`；表注放在表下方，用于说明 `n`、统计方法、缩写。
- 正文必须引用每一张表（“见表 1”）。

## 5. 图

作图要求详见 [fdu-lab-plot](../.agents/skills/fdu-lab-plot/SKILL.md) 与 `tools/labplot.py`，要点：

- 坐标轴写明量与单位，如 `时间（min）`、`平均动脉压（mmHg）`；刻度朝内，字号不小于 8 pt。
- 折线图标出每个数据点；柱状图和折线图的误差线表示什么（SD 或 SEM），在图注里写明。
- 同一组数据在全文用同一颜色与线型；黑白打印后仍能区分（用线型或标记，而不只靠颜色）。
- 图题格式：`图 1　题目`，写在图下方；图注写明 `n` 与误差线含义。
- 位图分辨率不低于 300 dpi；曲线图优先用矢量格式（PDF/SVG）。
- 原始记录曲线（如心电图、血压曲线）截图要标出时间标尺与给药点。

## 6. 参考文献（GB/T 7714—2015，顺序编码制）

```
[1] 严钰锋，马淑兰．功能学科实验教程[M]．2020．
[2] EDDLESTON M, BUCKLEY N A, EYER P, et al. Management of acute organophosphorus pesticide poisoning[J]. The Lancet, 2008, 371(9612): 597-607. DOI: 10.1016/S0140-6736(07)61202-1.
```

- 期刊 `[J]`、图书 `[M]`、学位论文 `[D]`、电子资源 `[EB/OL]`；作者多于 3 人时列前 3 位加“等”（英文 *et al.*）。
- 能给出 DOI 的给出 DOI。引用前用 `python tools/refcheck.py` 核对，核对不通过的条目不要写进报告。
- 教材页码可用 `python tools/kb.py cite 2.7` 生成。
