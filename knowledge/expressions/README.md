# 课本专业表述库

目的：让报告的措辞、术语与判定标准贴近《功能学科实验教程》，同时避免大段照抄。

每个实验一页 `ex_<编号>.md`，栏目固定：

| 栏目 | 内容 |
| --- | --- |
| 术语 | 课本用词（中文＋英文），`stylecheck.py` 据此检查你的报告用了哪些 |
| 目的与原理句式 | 按课本表述方式概括的句式，空白处填你自己的实验内容 |
| 方法措辞 | 动物、药品、操作、观察指标的规范说法与课本给出的判定标准 |
| 结果描述 | 结果段常用的陈述方式 |
| 讨论抓手 | 机制链、与预期不符时可用的解释方向（写成假设） |
| 出处 | 教材章节与页码；原文用 `python tools/rag.py search … --exp 编号 -c textbook --full` 在本机取回 |

说明：
- 教材受版权保护，本库**不收录教材原文段落**，只收术语、短语、句式和页码。需要原文时，在本机用你自己的教材 PDF 建索引后检索。
- 句式是按课本表述方式写的概括，不是课本原句；直接引用课本时请加引号并标注页码。
- 带 `（待核）` 的内容超出课本，需要你对照药理学、生理学或病理生理学教材确认。
- 通用写法见 [general.md](general.md)。
- 审校状态：`draft-ai`，尚未由教师审校。
