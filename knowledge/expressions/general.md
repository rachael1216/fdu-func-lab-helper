## 目的句式
- 观察……对……的影响，并分析其作用机制。
- 学习……模型的复制方法，观察……时……的变化。
- 通过……指标的测定与结果分析，加深对……（病因、机制、药物作用）的理解。

## 方法句式
- 取……（动物）1 只，称重（X kg），观察并记录其正常指标：……
- 用 X%（药品）X mg/kg（或 X mL），经耳缘静脉（腹腔、肌肉）缓慢注射。
- 待……（作用明显、曲线稳定）后，记录……（时间、数值）。
- 每次给药前先记录一段对照，给药后在标记处记录……
- 动物、药品、剂量与教材不同之处，如实写出，并说明原因。

## 讨论句式
- 本实验中……与预期一致，其机制可能是：……
- ……与预期不一致，可能的原因有：①……；②……。验证办法是……
- 本实验仅 1 只动物（n=1），结果存在个体差异，需结合全班数据分析。
- 以上结论仅限于本实验条件，不宜外推。

## 用词对照（口语 → 规范）
| 口语 | 规范 |
| --- | --- |
| 兔子、老鼠 | 家兔、小鼠或大鼠 |
| 打药、打针 | 给药、注射（并写途径） |
| 心跳变快、变慢 | 心率加快、减慢（给出次/min） |
| 血压变高、变低 | 血压升高、降低（给出 mmHg） |
| 很多、很大 | 给出数值或相对变化 |
| 死掉 | 死亡（给出时间） |

## 数字与单位
- 数值与单位间留空格：2.5 kg、0.5 mg/kg、37 ℃；百分号紧跟数字：27.3%。
- 浓度与剂量要区分：5%（浓度）、75 mg/kg（剂量）。
- 离子：K⁺、Ca²⁺、Na⁺；化学式下标：H₂O、BaCl₂。
