# 实验 2.1　心血管活动调节及药物的影响

> 简版卡片：给出机制骨架和写作抓手。细节（剂量、步骤、思考题全文）请用 `python tools/kb.py show 2.1` 查你自己的教材，并以**实际操作**为准。

## 一句话
记录颈总动脉血压和心率，观察夹闭颈总动脉、刺激迷走/降压神经及传出神经药物的效应，体会神经-体液调节。

## 机制链
1. **压力感受性反射**：动脉压↑ → 颈动脉窦/主动脉弓感受器兴奋 → 迷走↑、交感↓ → 心率↓、外周阻力↓ → 血压回降。
2. **夹闭颈总动脉**（近心端）→ 颈动脉窦压力↓ → 反射性交感↑、迷走↓ → 血压↑、心率↑。
3. **刺激降压神经（主动脉神经）传入端**：模拟压力↑ → 血压↓、心率↓；**刺激迷走**外周端：心率↓，强刺激可短暂停搏后逸搏。
4. **肾上腺素**（α+β）：心率、收缩力↑，皮肤黏膜内脏血管收缩，骨骼肌血管舒张（β₂）→ 收缩压明显↑；**去甲肾上腺素**（α₁>β₁）：血管强烈收缩，血压显著↑，但**反射性心率↓**；**异丙肾上腺素**（β₁+β₂）：心率↑，外周血管舒张 → 舒张压↓、脉压↑。
5. **阿托品**阻断 M₂ → 迷走张力解除，心率↑，并取消迷走刺激的效应。
6. **酚妥拉明**（α 阻断）后：肾上腺素的升压作用**翻转为降压**（只剩 β₂ 舒血管）；去甲肾上腺素升压减弱。**普萘洛尔**（β 阻断）后：异丙肾上腺素效应消失，肾上腺素升压（α）更突出、心率增快不明显。

## 预期现象
- 夹闭颈总动脉：血压↑
- 降压神经/迷走刺激：血压↓、心率↓
- 三种儿茶酚胺各异；酚妥拉明/普萘洛尔后的变化符合上述翻转

## 记录要点
基础血压/心率；每次处理前后的收缩压/舒张压/平均压/心率；药物剂量、给药时间、恢复间隔；刺激参数。

## 常见偏差与解释思路（写成"可能"，不要当结论）
- 前一药物作用未恢复就给下一个药 → 需充分恢复并设前后对照
- 导管凝血/气泡 → 压力波形失真
- 麻醉深度影响反射

## 讨论抓手
三种儿茶酚胺受体谱与剂量；"肾上腺素翻转"的机制；β 阻断后对三药的影响；压力感受性反射的意义。

## 临床联系
休克与升压药选择；嗜铬细胞瘤；β 阻断药/α 阻断药的临床应用及不良反应。
