# 快速开始：三种用法，选一种就行

| | 方案 A　网页粘贴 | 方案 B　dsh 本地网页（推荐） | 方案 C　只要模板 |
|---|---|---|---|
| 需要安装 | 无 | Node.js + dsh | Word 或 LaTeX |
| 需要 DeepSeek | 网页账号 | API Key | 不需要 |
| 能自动算数据 | ✗（给公式，你本地复核） | ✓ | — |
| 能自动出带封面的 Word/PDF | ✗（粘贴后本地生成） | ✓ | 手动填模板 |
| 上手难度 | ★ | ★★ | ★ |

> **关于 dsh**：本项目把它理解为 DeepSeek 的本地 agent 运行环境（DeepSeek Harness）。skill 的加载方式依据其公开说明编写，作者尚未在真机上完整验证；若与你看到的界面不一致，请开 Issue，或先用方案 A。

---

## 方案 A　网页粘贴（零安装）

1. 登录 <https://chat.deepseek.com>。
2. 在本仓库页面下载 ZIP（Code → Download ZIP）并解压，或直接打开 `prompts/` 里的说明。
3. 生成你这次实验的提示词：`python tools/make_prompt.py 2.7`（把 2.7 换成你的实验编号；没装 Python 也可以手动复制 `.agents/skills/fdu-lab-report/SKILL.md` 与对应 `knowledge/cards/ex_2.7.md` 的内容）。
4. 把整段提示词粘贴给 DeepSeek，然后按它的提问一组一组回答，粘贴你自己的原始记录。
5. 把最终 Markdown 粘进 `templates/word/功能学科实验报告模板.docx` 或用 `tools/build.py` 排版。

## 方案 B　dsh + skills（推荐）

**第 1 步：准备环境（一次性，约 10 分钟）**

1. 安装 Node.js ≥ 22.19（<https://nodejs.org>，选 LTS 以上版本）。终端运行 `node -v` 确认。
2. 安装 Python ≥ 3.10、pandoc：
   - Windows：`winget install JohnMacFarlane.Pandoc`
   - macOS：`brew install pandoc`
   - 然后 `pip install -r requirements.txt`
3. 申请 DeepSeek API Key：登录 <https://platform.deepseek.com> → API keys → 创建，**复制后妥善保存，不要发给别人、不要上传 GitHub**。账户需要少量余额，一份报告通常几毛钱量级（以官网定价为准）。

**第 2 步：获取仓库并启动**

```bash
git clone https://github.com/rachael1216/fdu-func-lab-helper.git
cd fdu-func-lab-helper
python tools/build.py --doctor          # 检查环境，缺什么会告诉你
npx @deepseek-ai/dsh web                # 启动本地网页，浏览器打开 http://127.0.0.1:3080
```

**第 3 步：在网页里配置**

1. Settings → Models：填入你的 API Key。
2. 工作目录选择本仓库文件夹（项目内 `.agents/skills` 会被自动发现，不需要另外安装 skill）。
3. 新建对话，输入：「我要写家兔高钾血症（实验 2.7）的报告，请用 fdu-lab-report 带我做。」

想在任意目录使用：`python tools/install_skills.py`（把 skill 复制到 `~/.dsh/skills`）。

**第 4 步：产出**
报告在 `reports/<实验名>/`（已被 git 忽略，不会误传）。

## 方案 C　只要模板

- Word：`templates/word/功能学科实验报告模板.docx`
- LaTeX：`templates/latex/` 整个文件夹（含 `fdureport.cls` 与封面图），XeLaTeX 编译，也可整体上传 Overleaf。
- 封面图 8 个主题在 `assets/covers/`，可自行替换。
