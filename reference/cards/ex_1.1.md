# 实验 1.1　神经干动作电位电生理实验

> 简版卡片：给出机制骨架和写作抓手。细节（剂量、步骤、思考题全文）请用 `python tools/kb.py show 1.1` 查你自己的教材，并以**实际操作**为准。

## 一句话
细胞外记录蟾蜍坐骨神经干**复合动作电位（CAP）**，测传导速度、不应期、刺激强度-幅度关系。

## 机制链
1. 神经干由许多阈值、直径不同的纤维组成：刺激强度↑ → 被**募集**的纤维数↑ → CAP 幅度↑，直到**最大刺激**（全部纤维兴奋）后不再增大；单根纤维遵循**全或无**，CAP 不是全或无。
2. **传导速度** v = 两对引导电极间距 d / 两个动作电位的时间差 Δt；纤维直径大、有髓、温度高 → 速度快。
3. **不应期**：双脉冲法，间隔缩短到第二个刺激不再引起反应 → 绝对不应期；间隔稍长，反应幅度降低 → 相对不应期。
4. **双相波形**：两引导电极先后接受兴奋波，电极 1 处负、电极 2 处正，相继出现 → 双相；压伤/阻断一端可得单相波。
5. 局麻药（如普鲁卡因、利多卡因）阻滞 Na⁺ 通道 → CAP 幅度↓、传导速度↓、最终阻断。

## 预期现象
- 阈下无反应 → 阈上出现 CAP → 幅度随强度增大至平台
- 缩短双刺激间隔：第二个 CAP 先变小后消失
- 加局麻药：幅度逐渐降低、潜伏期延长

## 记录要点
标本温度/浸润液；两对电极间距 d；刺激参数（波宽、强度）；每一步 CAP 幅度（mV）、潜伏期（ms）；双脉冲间隔；药物名称/浓度/作用时间。

## 常见偏差与解释思路（写成"可能"，不要当结论）
- 伪迹与动作电位混淆 → 看潜伏期随电极距离变化、随刺激强度变化的规律
- 标本干燥/受损导致幅度逐渐下降 → 注意保持湿润
- 引导电极与神经接触不良、接地问题

## 讨论抓手
CAP 与单纤维动作电位的区别；传导速度的影响因素；不应期的离子基础（Na⁺ 通道失活/恢复）；药物对 CAP 的影响机制。

## 临床联系
神经传导速度检查（周围神经病、脱髓鞘病变）；局部麻醉的作用机制。
