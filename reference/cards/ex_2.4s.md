# 实验 2.4（校本版）　利多卡因对氯化钡诱发家兔心律失常的保护作用

> 教材 2.4 用**哇巴因 + 豚鼠**；本校实际开展的是 **BaCl₂ + 家兔**，分组、剂量、给药时机以老师讲义和**你们实际操作**为准。教材要求"与指导不同要按实际写"，不要照抄教材。

## 一句话
BaCl₂ 阻断内向整流钾通道诱发**室性心律失常**；利多卡因（IB 类）阻滞钠通道，对心室性心律失常有效。全班一般分"利多卡因组 vs 生理盐水对照组"汇总比较。

## 机制链
1. **Ba²⁺ 阻断 I_K1**（内向整流 K⁺ 通道）→ K⁺ 外流↓ → 静息电位去极化、舒张期膜电位不稳 → 浦肯野纤维/心室肌 **4 期自动除极加速、异位起搏**，兴奋性↑ → **室性早搏（宽大畸形 QRS）、室速、室颤**。
2. 对其它 K⁺ 通道（如 I_Kr/I_Ks）的抑制及钙内流改变可使复极延长、离散度增大 → **折返**与**触发活动（后除极）**，使心律失常恶化（讨论时作为"可能的补充机制"，勿当唯一机制）。
3. **利多卡因（IB 类）**：优先阻滞**失活态/开放态**钠通道（使用依赖性，快速结合/解离），对**去极化、快频率**的心室组织作用强，对心房与正常窦性组织影响小；轻度缩短 APD、相对延长 ERP/APD；抑制浦肯野 4 期自律性。
4. 为何对 BaCl₂ 模型有效：该模型本质是**心室去极化状态下的异位自律性与触发活动**，正是 IB 类最擅长的靶点（也解释了它对缺血/洋地黄中毒性室性心律失常有效）。

## 预期现象（ECG）
| 阶段 | 表现 |
|---|---|
| 正常 | 规则窦律，P-QRS-T 清晰 |
| 注射 BaCl₂ 后数十秒 | P 波消失或与 QRS 脱节；**宽大畸形 QRS 的室早**（前无相关 P 波，T 波与主波反向），可呈二联律/成串 |
| 进一步 | 室速（连续宽 QRS，频率快）→ 室扑/室颤（波形杂乱、幅度低） |
| 利多卡因组 | 期望：室性心律失常减少/终止、转复窦律 |
| 对照组（生理盐水） | 心律失常持续或恶化，直至死亡 |

## 记录单
- 体重；BaCl₂ 浓度/剂量/体积/注射时长；利多卡因或生理盐水的浓度、**剂量（mg/kg）、体积、给药时刻与距心律失常出现的间隔**。
- 事件时间轴：注射起点 → 首次室早（潜伏期，s）→ 室速 → 室颤 → 给药 → 转复/死亡；每个事件的 ECG 标记。
- 抢救措施：心肺复苏、重复给药等是否实施。
- **全班汇总表**：组别（治疗/对照）、结局（转复/未转复/死亡）、潜伏期、给药时机。

## 计算与呈现
- 潜伏期用 `labcalc stats`；转复率比较用 `labcalc fisher -a 治疗转复 -b 治疗未转复 -c 对照转复 -d 对照未转复`。
- 全班仅 3 vs 3 时，Fisher 检验几乎不可能显著——**统计效力不足**本身要写进讨论，而不是勉强下"显著有效/无效"的结论。

## 常见"不理想"结果与解释思路
- **本组利多卡因抢救失败**：n=1 个体差异；给药延迟（已进入室颤，利多卡因对室颤转复作用有限）；给药速度/剂量；心律失常已较重（需电除颤等）；BaCl₂ 剂量相对过大。
- **对照组自行恢复**：自限性、个体差异。
- 与全班结果不一致时，以**全班汇总**为主证据，本组结果作个例描述。

## 讨论建议结构
4.1 BaCl₂ 致心律失常机制 ↔ ECG 逐图对应
4.2 利多卡因的抗心律失常机制与适用（IB 类的"状态/使用依赖"）
4.3 本组/全班结果：与预期是否一致，差异的解释（时机、剂量、n）
4.4 局限与改进（给药时机标准化、更多只数、同时记录血压）

## 临床联系
室性心律失常（急性心梗后、洋地黄中毒、长 QT 的尖端扭转型室速等）；**利多卡因的地位**：现多作为不能使用胺碘酮时的选择，对心房性心律失常无效；毒性：中枢（头晕、抽搐）、心血管抑制；低钾/钡中毒的联系。
