# 实验 8.1　药物半数致死量（LD50）的测定

## 一句话
质反应（死/活）实验：各组给不同剂量，求使 50% 动物死亡的剂量，并给出标准误与 95% 可信限；用于评价急性毒性与药物安全性（治疗指数）。

## 要点
1. **量反应 vs 质反应**：血压升高是量反应；存活/死亡是质反应（有或无）。
2. **剂量-反应曲线**：普通坐标为长尾 S 形；剂量取对数后对称 S 形；死亡率换成概率单位后与对数剂量成直线，50% 对应的剂量即 LD50。
3. **改良寇氏法**（本实验使用；Bliss 概率单位法最严谨，新药申报常用）：
   - LD50 = lg⁻¹[Xm − I(Σp − 0.5)]
   - S = I·√(Σp(1−p)/(n−1))
   - 95% 可信限 ≈ LD50 ± 4.5·S·LD50
   - Xm = 最大剂量的对数；I = 相邻剂量比的对数（高/低）；p = 各组死亡率（小数）；n = 每组动物数。
   - **前提**：各组 n 相同、剂量等比级数、理想情况下最低组 0%、最高组 100%。你的数据不满足时，要在报告里**写明**。
4. **治疗指数** TI = LD50/ED50（越大越安全）；量效曲线不平行时 TI 会失真，可用**安全范围** LD5/ED95。
5. **普鲁卡因毒性机制**：局麻药阻滞电压门控 Na⁺ 通道；过量时先抑制中枢**抑制性**神经元 → 躁动、震颤、惊厥（先兴奋），继而全面抑制 → 呼吸抑制、紫绀、死亡；心血管抑制。普鲁卡因为酯类，被血浆酯酶水解（可能过敏）。

## 剂量换算（不要在脑子里算）
- 溶液浓度 c%（g/100 mL）= 10c mg/mL；常用给药容量 0.1 mL/10 g 体重。
- 例：1.108% 溶液 → 11.08 mg/mL × 0.01 mL/g = 110.8 mg/kg。
- 每只小鼠注射体积 = 体重(g) × 0.01 mL；用 `labcalc dose` 或 `labcalc backdose` 核对。

## 记录单
- 每组：剂量（mg/kg）、药液浓度、注射容量、动物数（本组 / 全班汇总）、**观察时长**（教材步骤为 1 h，目的/表中也提到 2 h——写你们实际观察的时长）、死亡数、死亡时间。
- 逐组**中毒症状**：躁动、共济失调、抽搐、紫绀（口唇/虹膜/尾）、呼吸变化、死亡前表现。
- 注射失误：漏液、注射部位（腹腔）、小鼠称重误差。

## 计算与呈现
```bash
python tools/labcalc.py ld50 --doses 110.8 147.7 196.9 262.5 350 --n 28 --deaths 0 9 22 23 27
```
报告里写：`LD50 = 175.8 mg/kg，95% 可信限 161.5–190.2 mg/kg`，并列出 Xm、I、Σp 的代入值。表格列：组别 | 剂量 | 动物数 | 死亡数 | 死亡率 | p。

## 常见"不理想"结果与解释思路
- 最高剂量组死亡率 <100%、最低组 >0%：条件不完全满足，LD50 仍可估算但应写限制。
- 死亡率非单调：样本量小、注射失误（漏液）、个体差异、各小组操作与观察标准不一致（全班汇总的主要噪声来源）。
- 症状与剂量的对应（"剂量越高，起效越快、症状越重"）：用来补充 LD50 之外的定性证据。

## 讨论建议结构
4.1 普鲁卡因的作用与毒性机制（中枢：先兴奋后抑制；呼吸；心血管）↔ 各组观察到的症状
4.2 LD50 的意义与局限（TI、安全范围；动物福利与替代方法的趋势）
4.3 本次数据质量（等比级数、0/100%、n、汇总）

## 思考题要点
1. 为何新药都要测 LD50：急性毒性分级、确定后续试验起始剂量、计算治疗指数、与同类药物比较、法规要求。
2. A 药 LD50/ED50 = 50/5 = 10；B 药 40/2 = 20 → 按 TI，B 较安全；但要同时考虑量效曲线是否平行（安全范围）。
