# 实验 2.2　某些因素和药物对离体蛙心活动的影响

> 简版卡片：给出机制骨架和写作抓手。细节（剂量、步骤、思考题全文）请用 `python tools/kb.py show 2.2` 查你自己的教材，并以**实际操作**为准。

## 一句话
Straub 离体蛙心灌流，改变任氏液成分或加药，观察心率与收缩力。

## 机制链
1. 任氏液（含 Na⁺、K⁺、Ca²⁺ 等）可维持离体心脏较长时间的节律活动；改变离子成分就改变心肌电生理与兴奋-收缩耦联。
2. **0.65% NaCl（缺 K⁺、Ca²⁺）**：Ca²⁺ 缺乏 → 收缩力明显↓；心肌兴奋性下降，**停于舒张期**。
3. **↑Ca²⁺**：Ca²⁺ 内流↑ → 收缩力↑，高钙可使**舒张不全、停于收缩期**；对心率影响不如肾上腺素显著。
4. **↑K⁺**：静息电位去极化 → 抑制，心率↓、收缩力↓，**停于舒张期**。
5. **肾上腺素**：β₁ → cAMP↑ → PKA 磷酸化 L 型 Ca²⁺ 通道等 → 收缩力↑、心率↑，并**加快舒张**；**乙酰胆碱**：M₂ → 心率↓、收缩力↓。
6. 高 Ca²⁺ 与肾上腺素**相同点**：增强收缩力；**不同点**：Ca²⁺ 直接增加胞内钙，肾上腺素经 cAMP 通路且加快舒张和心率。

## 预期现象
- 低渗/无钙：收缩↓至停；高钙：增强后可僵直收缩；高钾：抑制；肾上腺素：增强增快；ACh：减慢减弱

## 记录要点
每步心率、收缩幅度（张力）、停于舒张/收缩；药物浓度和体积；换液与恢复。

## 常见偏差与解释思路（写成"可能"，不要当结论）
- 换液时机械冲击
- 各步骤间未恢复
- 标本老化

## 讨论抓手
各离子的作用机制；肾上腺素 vs 高钙；ACh 与迷走刺激的关系（Loewi 实验思路）。

## 临床联系
