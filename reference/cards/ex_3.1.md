# 实验 3.1　呼吸调节及药物影响

## 一句话
用**膈肌放电（及其积分曲线）**反映吸气中枢输出：幅度↔吸气强度，簇间隔/波宽↔呼吸快慢。比较化学刺激（N₂、CO₂、乳酸）、肺牵张反射（充气/抽气、切迷走）和药物（尼可刹米、吗啡）对其影响。

## 机制链
1. **节律起源**：延髓（含前包钦格复合体）产生基本节律，脑桥呼吸调整中枢使节律平滑；膈神经→膈肌放电。
2. **化学感受性反射**：
   - 外周化学感受器（颈动脉体、主动脉体）：对 **PO₂↓、PCO₂↑、H⁺↑** 敏感 → 兴奋呼吸；
   - 中枢化学感受器（延髓腹外侧）：对脑脊液 H⁺（由 CO₂ 透过血脑屏障生成）敏感；**CO₂ 是最重要的生理性刺激**；
   - 低氧对呼吸中枢本身是抑制性的，严重缺氧时外周兴奋被抵消，呼吸可转为抑制。
   - 血液中的 H⁺（乳酸）难以通过血脑屏障，主要经**外周**化学感受器起作用。
3. **肺牵张反射（Hering-Breuer）**：肺扩张 → 气道平滑肌牵张感受器兴奋 → **迷走神经传入** → 抑制吸气、促吸→呼转换（充气时吸气活动被抑制）；肺萎陷时反射性兴奋吸气。切断双侧迷走神经后，反射环路中断 → 呼吸**变深变慢**，且充气/抽气不再有效应。
4. **药物**：尼可刹米直接兴奋延髓呼吸中枢，并刺激颈动脉体化学感受器；吗啡（μ 受体激动）降低呼吸中枢对 CO₂ 的敏感性 → 呼吸抑制；尼可刹米可作解救（作用短，需慢推防惊厥）。

## 预期现象 ↔ 机制
| 处理 | 预期放电变化 | 机制 |
|---|---|---|
| 吸入 N₂ | 幅度↑、频率↑（早期） | PO₂↓→外周化学感受器 |
| 吸入 CO₂ | 明显加深加快 | 中枢+外周化学感受器；PCO₂↑、H⁺↑ |
| 吸气末充气 | 吸气放电被抑制/暂停 | 肺牵张反射 |
| 呼气末抽气 | 吸气放电增强/提前 | 肺萎陷反射 |
| 切断单侧迷走 | 变化不大或略变慢加深 | 传入减少一半 |
| 切断双侧迷走 | 深而慢；再充气/抽气无效应 | 反射环路中断 |
| 乳酸 | 加深加快 | 血液 H⁺ → 外周化学感受器 |
| 尼可刹米 | 加深加快 | 直接兴奋呼吸中枢 |
| 吗啡 | 减慢减弱 | μ 受体 → 对 CO₂ 敏感性↓ |

## 记录单
- 每个处理：起止时间、**实际给药量/气体流速与持续时间**、是否有标记。
- 放电：频率（簇数/时间或软件读数——**写明定义**）、簇间隔、**峰峰值/积分波高**；对照用"处理前稳定基线"，而不是笼统的"初始"。
- 手术/电极：电极位置、增益、阈值、等待时间 T0；基线是否漂移；是否有操作伪差（注射、移动）。

## 写结果的纪律（本实验最容易失分的地方）
- **幅度 ≠ 潮气量，放电簇频率 ≠ 呼吸频率**；只有同步的呼吸/气流记录才能谈通气量。
- 幅度、节律（频率/间隔）**分开描述**，不要写成"呼吸加快"。
- 用"放电幅度增大、簇间隔延长"这类**直接观察**的话，再用"与……原理相符"做解释。
- 若各截图不是连续记录，**不要**推断处理的先后因果。

## 常见"不理想"结果与解释思路
- 幅度↑但频率未↑：化学刺激早期以幅度为主；麻醉深度、电极接触、增益设置；记录窗口太短。
- 乳酸/尼可刹米强弱不好比：剂量/时间不等，基线不同——不能比较"药效强弱"。
- 切断迷走后"深慢"不明显：麻醉、电极状态、观察时间不足。
- 基线漂移/伪差：手术切口过大、电极未固定、注射干扰。

## 讨论建议结构

4.2 肺牵张反射（充气/抽气）与迷走传入
4.3 药物（乳酸、尼可刹米、吗啡）
4.4 迷走神经切断的意义与你的记录

## 思考题要点
1. CO₂ 与 N₂：CO₂ 同时兴奋中枢与外周、主要经 H⁺，效应强而稳；N₂ 经外周低氧驱动，严重低氧对中枢抑制。
2. 切断迷走后重复吸入气体：化学性反射仍在（吸 CO₂/N₂ 仍增强），但深度/频率关系改变；而牵张反射消失。

## 临床联系
COPD 的 CO₂ 潴留与"低流量吸氧"；阿片类过量与纳洛酮；呼吸兴奋药的有限适应症；Cheyne-Stokes 呼吸与化学感受器反馈；高原通气适应。
